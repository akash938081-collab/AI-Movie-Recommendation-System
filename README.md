# 🎬 AI Movie Recommendation System

An AI-based Movie Recommendation System built using Python and Streamlit. The system recommends similar movies based on movie content and displays movie posters and details.

## 🚀 Features

- 🎥 Select a movie from the list
- 🤖 Get 5 similar movie recommendations
- 🖼️ Display movie posters
- ⭐ Display movie ratings
- 📅 Display release dates
- 🎭 Display movie genres
- 📝 Display movie overview
- 🌐 Interactive web interface using Streamlit

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Machine Learning
- Content-Based Recommendation System

## 📂 Project Files

- app.py - Streamlit web application
- movies.pkl - Processed movie dataset
- poster_urls.pkl - Saved movie poster URLs
- similarity.pkl - Movie similarity matrix
- Untitled1.ipynb - Model development notebook
- requirements.txt - Required Python libraries

## ▶️ How to Run the Project

### 1. Clone the repository

git clone https://github.com/akash938081-collab/AI-Movie-Recommendation-System.git

### 2. Open the project folder

cd AI-Movie-Recommendation-System

### 3. Install dependencies

pip install -r requirements.txt

### 4. Run the application

streamlit run app.py

## 🎯 How It Works

The system uses a Content-Based Recommendation approach.

Movies are compared based on:

- Genres
- Keywords
- Cast
- Crew
- Movie overview

The similarity between movies is calculated and the top 5 similar movies are recommended.
